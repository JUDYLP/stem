开始练习

代码能跑，不代表你讲得出它为什么能跑。

免费 · 无需注册 · 无需 API Key

AI 生成 · 库存服务 stock · Redis 
@Service
public class StockService {
  public void deduct(String id) {
    // Check stock and deduct atomically
    int stock = redis.get("stock:" + id);
    if (stock > 0) {
      redis.set("stock:" + id, stock - 1);
    } } }

两个请求同时下单，库存只剩 1，会发生什么？

选一个回答，看看预设判定

判定结果

  • GET 和 SET 是两次独立操作。

  • 两个请求可能都读到 1，导致超卖。

  • 修复用 DECR 并检查结果，或用 Lua 脚本。

预设判定，未调用 AI
